# dotfiles

`dotfiles` stores a collection of configuration files for various programs.

## Prerequisites

- macOS: install [MacPorts](https://www.macports.org/install.php)

## Install

macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/Zhunio/dotfiles/refs/heads/main/install.sh | /bin/bash
```

## Setup GitHub CLI

```bash
gh auth login
```

## Applications and font

macOS:

- [Raycast](https://www.raycast.com/) — install separately
- [Victor Mono Nerd Font](https://www.nerdfonts.com/font-downloads) — installed automatically

## Uninstall

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Zhunio/dotfiles/refs/heads/main/uninstall.sh)"
```
